## 介绍

基于 [SbModbus](../README.md) 开发的调试助手。

## 功能

- 串口助手
  - 串口
  - TcpClient
  - TcpServer
  - UdpClient
  - UdpServer
- Modbus
  - FC01 读线圈
  - FC02 读离散输入
  - FC03 读保持寄存器
  - FC04 读输入寄存器
  - FC05 写线圈
  - FC06 写寄存器
  - FC10 写多个寄存器
